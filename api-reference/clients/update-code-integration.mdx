---
title: "Update Client Code Snippet"
api: "PATCH https://server.smartlead.ai/api/v1/client/{client_id}/code-integrations/{integration_id}"
description: "Update the name or code of a client's code snippet (whitelabel code integration)"
---

<Note>
Send at least one field. Only the fields you send are changed. Get `integration_id` from [Get Client by ID](/api-reference/clients/get-by-id) with `includeCodeIntegrations=true`.
</Note>

## Path Parameters

<ParamField path="client_id" type="number" required>
  Client ID
</ParamField>

<ParamField path="integration_id" type="number" required>
  Code snippet ID
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key (client API keys are not allowed)
</ParamField>

## Request Body

<ParamField body="snippet_name" type="string">
  Snippet name (1–255 characters)
</ParamField>

<ParamField body="snippet_code" type="string">
  Snippet code (at least 1 character)
</ParamField>

<RequestExample>

```bash cURL
curl -X PATCH "https://server.smartlead.ai/api/v1/client/456/code-integrations/12?api_key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"snippet_code": "<script>/* new link */</script>"}'
```

```python Python
import requests

response = requests.patch(
    "https://server.smartlead.ai/api/v1/client/456/code-integrations/12",
    params={"api_key": "YOUR_API_KEY"},
    json={"snippet_code": "<script>/* new link */</script>"}
)
print(response.json())
```

</RequestExample>

## Response Example

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "id": 12
  }
}
```

```json 404 - Client not found
{
  "error": "Client not found - Invalid client_id."

```

```json 404 - Snippet not found

```

</ResponseExample>
