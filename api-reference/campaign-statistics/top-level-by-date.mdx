description: "Fetch campaign top-level analytics filtered by date range"
---

## Path Parameters

<ParamField path="campaign_id" type="integer" required>
  The ID of the campaign
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your API key
</ParamField>

<ParamField query="start_date" type="string" required>
  Start date in YYYY-MM-DD format
</ParamField>

<ParamField query="end_date" type="string" required>
  End date in YYYY-MM-DD format
</ParamField>



<RequestExample>

```bash cURL
curl "https://server.smartlead.ai/api/v1/campaigns/12345/top-level-analytics-by-date?api_key=YOUR_API_KEY&start_date=2024-01-01&end_date=2024-01-31"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"
CAMPAIGN_ID = 12345

response = requests.get(
    f"https://server.smartlead.ai/api/v1/campaigns/{CAMPAIGN_ID}/top-level-analytics-by-date",
    params={
        "api_key": API_KEY,
        "start_date": "2024-01-01",
        "end_date": "2024-01-31"
    }
)

result = response.json()
print(result)
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';
const CAMPAIGN_ID = 12345;

const response = await fetch(
  `https://server.smartlead.ai/api/v1/campaigns/${CAMPAIGN_ID}/top-level-analytics-by-date?api_key=${API_KEY}&start_date=2024-01-01&end_date=2024-01-31`
);

const result = await response.json();
console.log(result);
```

## Response Fields

Counts are returned as strings.

<ResponseField name="bounce_count" type="string">
  Sends in the date range that bounced, for any reason.
</ResponseField>

<ResponseField name="sender_bounce_count" type="string">
  The subset of `bounce_count` caused by the **sending** mailbox rather than the recipient address, counted for leads categorised as Sender Originated Bounce. Always less than or equal to `bounce_count`.
</ResponseField>
