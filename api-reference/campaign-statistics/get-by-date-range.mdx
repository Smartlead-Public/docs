---
title: "Fetch Campaign Statistics by Date Range"
api: "GET https://server.smartlead.ai/api/v1/campaigns/{campaign_id}/analytics-by-date"
description: "Fetch campaign statistics using the campaign's ID filtered by date range"
---

## Path Parameters

<ParamField path="campaign_id" type="integer" required>
  The ID of the campaign
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your API key
</ParamField>

<ParamField query="start_date" type="string" required>
  Start date in YYYY-MM-DD format
</ParamField>

<ParamField query="end_date" type="string" required>
  End date in YYYY-MM-DD format
</ParamField>

<ParamField query="time_zone" type="string">
  IANA timezone string (e.g. "America/New_York")
</ParamField>

<Warning>
The range between `start_date` and `end_date` must be **30 days or less**. A wider range returns `400 Bad Request`.
</Warning>

## Reply Fields

| Field | What it counts |
|---|---|
| `total_reply_count` | Every reply, with no exclusions |
| `non_ooo_reply_count` | Replies from leads not categorised as out-of-office |
| `reply_count` | Replies excluding any flagged as ignored |

Out-of-office replies are `total_reply_count - non_ooo_reply_count`.

`non_ooo_reply_count` comes from reply categorisation alone, so it does **not** depend on the per-campaign *ignore out-of-office* setting.

<Warning>
`non_ooo_reply_count` can be higher than `reply_count`. `reply_count` also drops manually-ignored replies and replies whose sender is not the lead, neither of which is out-of-office. Compare `non_ooo_reply_count` against `total_reply_count`.
</Warning>

See [Get Campaign Analytics by Date Range](/api-reference/campaigns/get-analytics-by-date) for the full field list.

<RequestExample>

```bash cURL
curl "https://server.smartlead.ai/api/v1/campaigns/12345/analytics-by-date?api_key=YOUR_API_KEY&start_date=2024-01-01&end_date=2024-01-31"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"
CAMPAIGN_ID = 12345

response = requests.get(
    f"https://server.smartlead.ai/api/v1/campaigns/{CAMPAIGN_ID}/analytics-by-date",
    params={
        "api_key": API_KEY,
        "start_date": "2024-01-01",
        "end_date": "2024-01-31"
    }
)

result = response.json()
print(result)
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';
const CAMPAIGN_ID = 12345;

const response = await fetch(
  `https://server.smartlead.ai/api/v1/campaigns/${CAMPAIGN_ID}/analytics-by-date?api_key=${API_KEY}&start_date=2024-01-01&end_date=2024-01-31`
);

const result = await response.json();
console.log(result);
```
