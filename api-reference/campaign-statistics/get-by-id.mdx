---
title: "Fetch Campaign Statistics by Campaign ID"
api: "GET https://server.smartlead.ai/api/v1/campaigns/{campaign_id}/statistics"
description: "Fetch campaign statistics using the campaign's ID"
---

## Path Parameters

<ParamField path="campaign_id" type="integer" required>
  Campaign ID
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your API key
</ParamField>

<ParamField query="offset" type="integer">
  List offset
</ParamField>

<ParamField query="limit" type="integer">
  Max number of stats to return (max 1000)
</ParamField>

<ParamField query="email_sequence_number" type="integer">
  Single sequence number (min: 1, max: 20)
</ParamField>

<ParamField query="email_status" type="string">
  Filter by email status. Possible values: `opened`, `clicked`, `replied`, `unsubscribed`, `bounced`
</ParamField>

<ParamField query="sent_time_start_date" type="string">
  Filters campaign stats with sent time greater than this date. Format: `2023-10-16 10:33:02.000Z`
</ParamField>

<ParamField query="sent_time_end_date" type="string">
  Filters campaign stats with sent time less than this date. Format: `2023-10-16 10:33:02.000Z`
</ParamField>



<RequestExample>

```bash cURL
curl "https://server.smartlead.ai/api/v1/campaigns/12345/statistics?api_key=YOUR_API_KEY&limit=100&offset=0"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"
CAMPAIGN_ID = 12345

response = requests.get(
    f"https://server.smartlead.ai/api/v1/campaigns/{CAMPAIGN_ID}/statistics",
    params={
        "api_key": API_KEY,
        "limit": 100,
        "offset": 0
    }
)

result = response.json()
print(result)
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';
const CAMPAIGN_ID = 12345;

const response = await fetch(
  `https://server.smartlead.ai/api/v1/campaigns/${CAMPAIGN_ID}/statistics?api_key=${API_KEY}&limit=100&offset=0`
);

const result = await response.json();
console.log(result);
```

## Response Fields

<ResponseField name="hasMore" type="boolean">
  Whether more leads exist beyond this page. Advance with `offset`.
</ResponseField>

<ResponseField name="data" type="array">
  One entry per lead, each with the send and reply `history` for that lead.

  <Expandable title="properties">
    <ResponseField name="sender_bounce" type="boolean">
      Whether this lead is categorised as a **sender-originated bounce** — a bounce caused by the sending mailbox rather than the recipient address. Always a boolean; `false` when the lead has no category.
    </ResponseField>
    <ResponseField name="last_seq_num" type="number">
      The sequence step the lead has reached.
    </ResponseField>
    <ResponseField name="history" type="array">
      Chronological `SENT` and `REPLY` events for the lead.
    </ResponseField>
  </Expandable>
</ResponseField>
