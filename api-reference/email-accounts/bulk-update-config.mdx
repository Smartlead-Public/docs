---
title: "Bulk Update Email Account Config"
api: "POST https://server.smartlead.ai/api/v1/email-accounts/bulk-update-email-account-config"
description: "Update sending settings, warmup settings, tags and client for many email accounts in one call"
---

<Note>
Only the fields you send in `updateData` are changed. IDs that are not email accounts in your account are skipped. Accounts are processed in batches of 100.
</Note>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Request Body

<ParamField body="emailAccountIds" type="number[]" required>
  Email account IDs to update (positive integers, at least one)
</ParamField>

<ParamField body="updateData" type="object">
  Fields to update
  <Expandable title="Sending settings">
    <ParamField body="messagePerDay" type="number">Maximum campaign emails per day</ParamField>
    <ParamField body="minTimeToWaitInMins" type="number">Minimum gap between campaign emails, in minutes</ParamField>
    <ParamField body="fromName" type="string">Sender name</ParamField>
    <ParamField body="signature" type="string">Email signature (HTML)</ParamField>
    <ParamField body="customTrackingDomain" type="string">Custom tracking domain. `http://` / `https://` is removed and the CNAME and SSL are verified.</ParamField>
  </Expandable>
  <Expandable title="Warmup settings">
    <ParamField body="status" type="string">Warmup status: `ACTIVE` or `INACTIVE`. Accounts whose warmup is blocked are set back to `INACTIVE` when `ACTIVE` is sent.</ParamField>
    <ParamField body="maxEmailPerDay" type="number">Warmup emails per day (1–250). When `warmupMinCount` / `warmupMaxCount` are not sent, they are set to `maxEmailPerDay - 5` (or `maxEmailPerDay` if that is 5 or less) and `maxEmailPerDay`.</ParamField>
    <ParamField body="warmupMinCount" type="number">Minimum warmup emails per day (1–50). When `warmupMaxCount` is also sent, it can't be greater than `warmupMaxCount`.</ParamField>
    <ParamField body="warmupMaxCount" type="number">Maximum warmup emails per day (1–250)</ParamField>
    <ParamField body="replyRate" type="number">Warmup reply rate percentage (1–100)</ParamField>
    <ParamField body="isRampupEnabled" type="boolean">Enable warmup ramp-up</ParamField>
    <ParamField body="rampupValue" type="number">Daily ramp-up increase</ParamField>
    <ParamField body="sendWarmupsOnlyOnWeekdays" type="boolean">Send warmup emails only on weekdays</ParamField>
    <ParamField body="autoAdjustWarmup" type="boolean">Automatically adjust warmup volume</ParamField>
    <ParamField body="useCustomDomain" type="boolean">Warm up the custom domain tracking link</ParamField>
    <ParamField body="warmupTagIdentifier" type="string">Warmup key ID (letters, numbers, `_` and `-` only)</ParamField>
    <ParamField body="dailyReplyLimit" type="number">Daily warmup reply limit (8–80)</ParamField>
  </Expandable>
  <Expandable title="Tags and client">
    <ParamField body="tags" type="number[]">Tag IDs (at least one). Replaces each account's current tags with this list. To remove tags, use [Remove Tags from Email Accounts](/api-reference/email-account-tags/remove).</ParamField>
    <ParamField body="clientId" type="number">Client ID to assign the accounts to</ParamField>
  </Expandable>
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://server.smartlead.ai/api/v1/email-accounts/bulk-update-email-account-config?api_key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "emailAccountIds": [101, 102, 103],
    "updateData": {
      "messagePerDay": 30,
      "minTimeToWaitInMins": 10,
      "status": "ACTIVE",
      "maxEmailPerDay": 40,
      "warmupMinCount": 30,
      "warmupMaxCount": 40,
      "replyRate": 30,
      "isRampupEnabled": true,
      "rampupValue": 5,
      "sendWarmupsOnlyOnWeekdays": true,
      "tags": [20680, 21926],
      "clientId": 456
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://server.smartlead.ai/api/v1/email-accounts/bulk-update-email-account-config",
    params={"api_key": "YOUR_API_KEY"},
    json={
        "emailAccountIds": [101, 102, 103],
        "updateData": {
            "status": "ACTIVE",
            "maxEmailPerDay": 40,
            "warmupMinCount": 30,
            "warmupMaxCount": 40,
            "replyRate": 30,
            "sendWarmupsOnlyOnWeekdays": True
        }
    }
)
print(response.json())
```
