---
title: "Get Leads Status Count"
api: "GET https://server.smartlead.ai/api/v1/leads/status-count"
description: "Get per-campaign lead counts by status across all active campaigns"
---

<Note>
Returns the number of leads in a given status (default `STARTED` — not yet contacted) broken down by campaign. Only campaigns with status `ACTIVE` are included.
</Note>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<ParamField query="status" type="string" default="STARTED">
  Lead status to count. If omitted, defaults to `STARTED`.

  Valid values:
  - `STARTED` — Not yet contacted
  - `INPROGRESS` — Currently being emailed
  - `STOPPED` — Stopped
  - `PAUSED` — Paused
  - `BLOCKED` — Blocked
  - `COMPLETED` — Completed the sequence
</ParamField>

<ParamField query="client_id" type="number">
  Scope results to a specific client (for agency/white-label accounts). If the API key belongs to a client, this is applied automatically.
</ParamField>

<RequestExample>

```bash cURL
curl -G "https://server.smartlead.ai/api/v1/leads/status-count" \
  --data-urlencode "api_key=YOUR_API_KEY" \
  --data-urlencode "status=STARTED"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.get(
    "https://server.smartlead.ai/api/v1/leads/status-count",
    params={
        "api_key": API_KEY,
        "status": "STARTED"
    }
)

data = response.json()
print(f"Total leads: {data['total_leads']} across {data['total_campaigns']} campaigns")
for campaign in data["campaigns"]:
    print(f"  {campaign['campaign_name']}: {campaign['leads_count']} leads")
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';

const params = new URLSearchParams({
  api_key: API_KEY,

});

  console.log(`  ${c.campaign_name}: ${c.leads_count} leads`)
);
```

</RequestExample>

## Response Fields

<ResponseField name="lead_status" type="string">
  The lead status that was counted (echoes the `status` query parameter or `"STARTED"` by default)
</ResponseField>

<ResponseField name="campaign_status" type="string">
  Always `"ACTIVE"` — only active campaigns are included
</ResponseField>

<ResponseField name="client_id" type="number | null">
  The client ID filter applied, or `null` if not scoped to a client
</ResponseField>

<ResponseField name="total_leads" type="number">
  Sum of matching leads across all active campaigns
</ResponseField>

<ResponseField name="total_campaigns" type="number">
  Number of active campaigns returned
</ResponseField>

<ResponseField name="campaigns" type="array">
  Per-campaign breakdown

  <Expandable title="Campaign object properties">
    <ResponseField name="campaigns[].campaign_id" type="number">
      Campaign ID
    </ResponseField>

    <ResponseField name="campaigns[].campaign_name" type="string">
      Campaign name
    </ResponseField>

    <ResponseField name="campaigns[].leads_count" type="number">
      Number of leads in the requested status for this campaign
    </ResponseField>
  </Expandable>
</ResponseField>
