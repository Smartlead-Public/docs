---
title: "Get Lead Sequence Details"
api: "GET https://server.smartlead.ai/api/v1/leads/{leadMapId}/sequence-details"
description: "Get the send status of every sequence step for a lead in a campaign"
---

<Note>
Returns one entry per email stats row for the lead map, in all statuses (for example `SENT` and `STOPPED`), ordered by `sent_time`. Get `leadMapId` from [Get Lead Campaign Overview](/api-reference/leads/campaign-overview) (`id`) or `campaign_lead_map_id` from the campaign's leads.
</Note>

## Path Parameters

<ParamField path="leadMapId" type="number" required>
  Lead map ID (positive integer)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key (client API keys are not allowed)
</ParamField>

<ParamField query="campaignId" type="number">
  Campaign ID to restrict the results to (positive integer)
</ParamField>

<RequestExample>

```bash cURL
curl "https://server.smartlead.ai/api/v1/leads/987654/sequence-details?api_key=YOUR_KEY&campaignId=123"
```

```python Python
import requests

response = requests.get(
    "https://server.smartlead.ai/api/v1/leads/987654/sequence-details",
    params={"api_key": "YOUR_API_KEY", "campaignId": 123}
)
for step in response.json()["data"]:
    print(step["email_campaign_seq_id"], step["status"])
```

</RequestExample>

## Response

<ResponseField name="data" type="array">
  <Expandable title="items">
    <ResponseField name="status" type="string">Send status of the step</ResponseField>
    <ResponseField name="sent_time" type="string | null">When the step was sent</ResponseField>
    <ResponseField name="status_message" type="string | null">Status message</ResponseField>
    <ResponseField name="email_campaign_seq_id" type="number">Sequence ID</ResponseField>
  </Expandable>
</ResponseField>
