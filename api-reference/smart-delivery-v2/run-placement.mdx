<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

A light call to poll while a run is sending or collecting. For the full scored report use [Get Run Report](/api-reference/smart-delivery-v2/run-report).

## Path Parameters

<ParamField path="id" type="string" required>
  Run ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Response Fields

<ResponseField name="runId" type="string">Run ID</ResponseField>
<ResponseField name="status" type="string">Run status</ResponseField>
<ResponseField name="held" type="boolean">`true` when the test is paused and unsent emails are waiting</ResponseField>
<ResponseField name="collectingUntil" type="string | null">End of the window in which results are collected</ResponseField>
<ResponseField name="resultsExpectedAt" type="string | null">When the final results are expected</ResponseField>
<ResponseField name="nextSendAt" type="string | null">Planned time of the next email still to go out</ResponseField>
<ResponseField name="lastSendAt" type="string | null">Planned time of the last email</ResponseField>
<ResponseField name="sent" type="number">Emails sent so far</ResponseField>
<ResponseField name="unsent" type="number">Emails still to be sent</ResponseField>
<ResponseField name="totals" type="object">Placement counts for the whole run: `inbox`, `tab`, `spam`, `missing`, `unreadable`, `unconfirmed`, `notSent`, `pending`, `bounced`, `total`, `measured` and `percent` (`inbox`, `tab`, `spam`, `missing` as a share of `measured`, or `null`)</ResponseField>
<ResponseField name="byProvider" type="array">Same counts per `provider`</ResponseField>
<ResponseField name="bySender" type="array">Same counts per `senderEmail`</ResponseField>
<ResponseField name="byProviderAndSender" type="array">Same counts per `provider` and `senderEmail`</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Run not found (`RUN_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
