api: "PUT https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/{id}/share"
description: "Create (or rotate) the read-only share link of a test"
---

<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. Contact support@smartlead.ai for access.
</Note>

## Overview

Creates a read-only link to the test's results. Calling it again rotates the link and the previous one stops working. The token is shown once; only its hash is stored.

## Path Parameters

<ParamField path="id" type="string" required>
  Test ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b/share?api_key=YOUR_KEY"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.put(
    "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b/share",
    params={"api_key": API_KEY}
)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';

const response = await fetch(
  `https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b/share?api_key=${API_KEY}`,
  {
    method: 'PUT'
  }
);
console.log(await response.json());
```

</RequestExample>

## Response Fields

<ResponseField name="token" type="string">Share token. Shown once</ResponseField>
<ResponseField name="url" type="string">Path of the shared view, `/v2/sd/shared/{token}`</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Test not found
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
