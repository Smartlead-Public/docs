---

<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Use it to follow a run while it sends and while results come in. Once `status` is `COMPLETED` the report is ready: see [Get Run Report](/api-reference/smart-delivery-v2/run-report).

## Path Parameters

<ParamField path="id" type="string" required>
  Run ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>


## Response Fields

<ResponseField name="id" type="string">Run ID (UUID)</ResponseField>
<ResponseField name="runNo" type="number">Run number within the test, starting at 1</ResponseField>
<ResponseField name="status" type="string">`QUEUED`, `SENDING`, `COLLECTING`, `COMPLETED`, `FAILED`, `SKIPPED` or `CANCELLED`</ResponseField>
<ResponseField name="statusReason" type="string | null">Why a run failed, was skipped or cancelled</ResponseField>
<ResponseField name="scheduledFor" type="string">When the run was due to start</ResponseField>
<ResponseField name="contentSnapshot" type="object | null">The email content that was sent (subject, body and the lead used for merge tags)</ResponseField>
<ResponseField name="skippedSenders" type="array | null">Senders left out of the run, with the reason</ResponseField>
<ResponseField name="seedFallback" type="boolean">`true` when some emails went to a different seed than first planned</ResponseField>
<ResponseField name="completedAt" type="string | null">When the run completed</ResponseField>
<ResponseField name="createdAt" type="string">Creation time</ResponseField>
<ResponseField name="held" type="boolean">`true` when the test is paused and this run's unsent emails are waiting</ResponseField>
<ResponseField name="test" type="object | null">`id`, `name`, `type` and `status` of the test the run belongs to</ResponseField>
<ResponseField name="assignments" type="array">
  One item per email
  <Expandable title="email">
    <ResponseField name="id" type="number">Email ID within the run (the `assignmentId` of the trace, headers and emails endpoints)</ResponseField>
    <ResponseField name="senderEmail" type="string">Sending mailbox</ResponseField>
    <ResponseField name="provider" type="string">Provider code of the seed inbox</ResponseField>
    <ResponseField name="sendStatus" type="string">`PLANNED`, `SENDING`, `SENT`, `FAILED` or `SKIPPED`</ResponseField>
    <ResponseField name="errorCode" type="string | null">Why the send failed</ResponseField>
    <ResponseField name="placement" type="string">`PENDING`, `INBOX`, `TAB`, `SPAM`, `MISSING`, `UNREADABLE`, `NOT_SENT`, `UNCONFIRMED` or `BOUNCED`</ResponseField>
    <ResponseField name="placementDetail" type="string | null">How the placement was decided</ResponseField>
    <ResponseField name="sendAt" type="string | null">Planned send time</ResponseField>
    <ResponseField name="sentAt" type="string | null">When it was sent</ResponseField>
    <ResponseField name="foundAt" type="string | null">When it was found at the provider</ResponseField>
    <ResponseField name="minutesAfterSend" type="number | null">Minutes from send to found</ResponseField>
  </Expandable>
</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Run not found (`RUN_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
