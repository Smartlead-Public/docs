<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Shows what happened to a single email: when it was sent, how often it was looked for and why it got its placement. The seed address is never returned.

## Path Parameters

<ParamField path="id" type="string" required>
  Run ID (UUID)
</ParamField>

<ParamField path="assignmentId" type="number" required>
  Email ID from [Get Run](/api-reference/smart-delivery-v2/get-run) (`assignments[].id`)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Response Fields

<ResponseField name="email" type="object">
  <Expandable title="email">
    <ResponseField name="id" type="number">Email ID</ResponseField>
    <ResponseField name="senderEmail" type="string">Sending mailbox</ResponseField>
    <ResponseField name="provider" type="string">Provider code</ResponseField>
    <ResponseField name="sendStatus" type="string">Send status</ResponseField>
    <ResponseField name="errorCode" type="string | null">Why the send failed</ResponseField>
    <ResponseField name="placement" type="string">Placement</ResponseField>
    <ResponseField name="placementDetail" type="string | null">How the placement was decided</ResponseField>
    <ResponseField name="sentAt" type="string | null">Sent time</ResponseField>
    <ResponseField name="foundAt" type="string | null">Found time</ResponseField>
    <ResponseField name="matchedBy" type="string | null">How the received copy was matched to the sent email</ResponseField>
    <ResponseField name="checksCount" type="number">Times the seed inbox was checked</ResponseField>
    <ResponseField name="lastCheckedAt" type="string | null">Last check</ResponseField>
    <ResponseField name="checkDeadline" type="string | null">When checking stops</ResponseField>
    <ResponseField name="minutesAfterSend" type="number | null">Minutes from send to found</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="events" type="array">Event log, oldest first: `at`, `type`, `detail`</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Run or email not found (`RUN_NOT_FOUND`, `EMAIL_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
