---

<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. Contact support@smartlead.ai for access.
</Note>

## Overview

Seed addresses are not returned; each item shows the provider and the placement of the email that mailbox sent to it.

## Path Parameters

<ParamField path="id" type="string" required>
  Run ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>


## Response Fields

<ResponseField name="seeds" type="array">
  <Expandable title="seed">
    <ResponseField name="senderEmail" type="string">Sending mailbox</ResponseField>
    <ResponseField name="family" type="string">Provider family</ResponseField>
    <ResponseField name="provider" type="string">Provider code</ResponseField>
    <ResponseField name="placement" type="string">Placement</ResponseField>
    <ResponseField name="placementDetail" type="string | null">How the placement was decided</ResponseField>
    <ResponseField name="delaySeconds" type="number | null">Seconds from send to receipt, when a copy was captured</ResponseField>
  </Expandable>
</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Run not found (`RUN_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
