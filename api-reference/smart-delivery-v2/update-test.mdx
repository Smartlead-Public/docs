<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Send only the fields you want to change. At least one field is required.

`schedule` is one of:

- `{ "frequency": "DAILY", "timeOfDay": "09:00", "timezone": "America/New_York" }`
- `{ "frequency": "WEEKLY", "weekdays": [1, 3, 5], "timeOfDay": "09:00", "timezone": "America/New_York" }` (`weekdays` are numbers 1 to 7)
- `{ "frequency": "EVERY_N_DAYS", "everyNDays": 3, "timeOfDay": "09:00", "timezone": "America/New_York" }` (`everyNDays` 2 to 90)

`timeOfDay` is `HH:mm` (24 hours) and `timezone` an IANA timezone name.

## Path Parameters

<ParamField path="id" type="string" required>
  Test ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Body Parameters

<ParamField body="name" type="string">
  New name
</ParamField>

<ParamField body="description" type="string | null">
  New description, or `null` to clear it
</ParamField>

<ParamField body="folderId" type="number | null">
  Folder ID, or `null` to take the test out of its folder
</ParamField>

<ParamField body="schedule" type="object">
  `AUTO` tests only: the new schedule
</ParamField>

<ParamField body="sendAllAtOnce" type="boolean">
  Send every email of a run together
</ParamField>

<ParamField body="sendGap" type="object">
  `{ "amount": 10, "unit": "minutes" }`. Not together with `sendAllAtOnce: true`
</ParamField>

## Response Fields

<ResponseField name="id" type="string">Test ID (UUID). Use it in every `/tests/{id}` path.</ResponseField>
<ResponseField name="name" type="string">Test name</ResponseField>
<ResponseField name="description" type="string | null">Test description</ResponseField>
<ResponseField name="type" type="string">`MANUAL` (one run, started now) or `AUTO` (recurring runs on a schedule)</ResponseField>
<ResponseField name="status" type="string">`ACTIVE`, `PAUSED`, `COMPLETED` or `STOPPED`</ResponseField>
<ResponseField name="statusReason" type="string | null">Why the test is in this status, for example `USER_PAUSED`, `USER_STOPPED` or `SCHEDULE_ENDED`</ResponseField>
<ResponseField name="folderId" type="number | null">Folder the test is in</ResponseField>
<ResponseField name="campaignId" type="number">Smartlead campaign whose email is tested</ResponseField>
<ResponseField name="sequenceId" type="number">Sequence step that is tested</ResponseField>
<ResponseField name="variantId" type="number | null">A/B variant tested, or `null` for the step's base email</ResponseField>
<ResponseField name="seedsPerSenderPerProvider" type="number">Seed inboxes each sender mails per provider</ResponseField>
<ResponseField name="sendAllAtOnce" type="boolean">`true` when all emails of a run go out together, `false` when they are spread by `sendGapMinutes`</ResponseField>
<ResponseField name="sendGapMinutes" type="number | null">Minutes between emails when they are spread out</ResponseField>
<ResponseField name="textOnly" type="boolean">Whether the emails are sent as text only (no HTML)</ResponseField>
<ResponseField name="schedule" type="object | null">`AUTO` tests: the schedule (see Create Deliverability Test)</ResponseField>
<ResponseField name="startsAt" type="string | null">`AUTO` tests: first run time (ISO 8601)</ResponseField>
<ResponseField name="endsAt" type="string | null">`AUTO` tests: the date after which no run starts</ResponseField>
<ResponseField name="maxRuns" type="number | null">`AUTO` tests: the number of runs after which the test completes</ResponseField>
<ResponseField name="nextRunAt" type="string | null">`AUTO` tests: when the next run starts</ResponseField>
<ResponseField name="runsCreated" type="number">Runs created so far</ResponseField>
<ResponseField name="createdAt" type="string">Creation time (ISO 8601)</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Test or folder not found
</ResponseField>

<ResponseField name="409" type="Error">
  Only `AUTO` tests have a schedule (`INVALID_STATE`)
</ResponseField>

<ResponseField name="422" type="Error">
  The new schedule has no run before `endsAt` (`SCHEDULE_HAS_NO_RUNS`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
