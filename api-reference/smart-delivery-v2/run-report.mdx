<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Returns the score, placement counts, breakdowns and diagnostics (blocklists, DNS, content, SpamAssassin, sender mailboxes) of a completed run. Until the report is built the response is `{ "ready": false, "status": "..." }`: poll [Get Run Placement](/api-reference/smart-delivery-v2/run-placement) or this endpoint until `ready` is `true`.

## Response Fields

<ResponseField name="ready" type="boolean">`false` while the report is not built yet. Then only `status` follows</ResponseField>
<ResponseField name="runId" type="string">Run ID</ResponseField>
<ResponseField name="completedAt" type="string">When the run completed</ResponseField>
<ResponseField name="score" type="number | null">Deliverability score, 0 to 100</ResponseField>
<ResponseField name="band" type="string | null">`poor` (below 40), `fair` (40 to 79) or `good` (80 and above)</ResponseField>
<ResponseField name="parts" type="array">The score's parts (`placement`, `auth`, `content`, `reputation`, `hygiene`) with `weight` and `value` (0 to 1, `null` when not available for this run)</ResponseField>
<ResponseField name="counts" type="object">Counts for the emails sent: `expected`, `sent`, `failed`, `inbox`, `tab`, `spam`, `missing`, `unreadable`, `notSent`, `unconfirmed`, `bouncedSeed`, `bouncedSender`, `bouncedUnknown`, `spfFail`, `dkimFail`, `dmarcFail`, and `inboxRate` (inbox share of the emails that reached a verdict, 0 to 1, or `null` when none did). Seed-side bounces (`bouncedSeed`) are left out of the placement rate; sender-side and unknown bounces count as not delivered.</ResponseField>
<ResponseField name="timeToInbox" type="object">`medianMs` and `p90Ms`: time from send to inbox</ResponseField>
<ResponseField name="headline" type="object | null">One-line summary of the result</ResponseField>
<ResponseField name="baseline" type="object | null">How the score compares with other Smart Delivery tests</ResponseField>
<ResponseField name="insights" type="object | null">The issues found and how to fix them, and the checks that passed</ResponseField>
<ResponseField name="captureIncomplete" type="boolean">`true` when a copy of some received emails could not be stored, so some details are missing</ResponseField>
<ResponseField name="seedFallback" type="boolean">`true` when some emails went to a different seed than first planned</ResponseField>
<ResponseField name="byProvider" type="array">`provider` and `counts` per provider</ResponseField>
<ResponseField name="bySender" type="array">`emailAccountId`, `senderEmail`, `sendingDomain` and `counts` per sender</ResponseField>
<ResponseField name="matrix" type="array">`provider`, `emailAccountId` and `counts` for every provider and sender pair</ResponseField>
<ResponseField name="diagnostics" type="object">`blacklists`, `dns`, `content`, `spamAssassin` and `senders` checks</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Run not found (`RUN_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
