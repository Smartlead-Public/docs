<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Creates a Smart Delivery v2 (Deliverability Test) test: it sends the chosen sequence email from your sender mailboxes to seed inboxes at the chosen providers, then reports whether each email landed in the inbox, a tab or spam. A `MANUAL` test starts one run immediately; an `AUTO` test starts runs on its `schedule`. Each run uses one run credit.

`schedule` is one of:

- `{ "frequency": "DAILY", "timeOfDay": "09:00", "timezone": "America/New_York" }`
- `{ "frequency": "WEEKLY", "weekdays": [1, 3, 5], "timeOfDay": "09:00", "timezone": "America/New_York" }` (`weekdays` are numbers 1 to 7)
- `{ "frequency": "EVERY_N_DAYS", "everyNDays": 3, "timeOfDay": "09:00", "timezone": "America/New_York" }` (`everyNDays` 2 to 90)

`timeOfDay` is `HH:mm` (24 hours) and `timezone` an IANA timezone name.

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Body Parameters

<ParamField body="type" type="string" required>
  `MANUAL` (one run, started now) or `AUTO` (recurring runs)
</ParamField>

<ParamField body="name" type="string" required>
  Test name, up to 200 characters
</ParamField>

<ParamField body="description" type="string">
  Up to 2000 characters
</ParamField>

<ParamField body="folderId" type="number">
  Folder to put the test in
</ParamField>

<ParamField body="campaignId" type="number" required>
  Smartlead campaign whose email is tested
</ParamField>

<ParamField body="sequenceId" type="number" required>
  Sequence step to test
</ParamField>

<ParamField body="variantId" type="number | null">
  A/B variant to test. Leave out for a step without variants
</ParamField>

<ParamField body="providerIds" type="number[]" required>
  1 to 20 provider IDs from [List Seed Providers](/api-reference/smart-delivery-v2/providers), no duplicates
</ParamField>

<ParamField body="emailAccountIds" type="number[]" required>
  1 to 1000 Smartlead email account IDs to send from. They must be attached to the campaign, and your plan limits how many one test may use (see [Get Plan Limits](/api-reference/smart-delivery-v2/limits))
</ParamField>

<ParamField body="sendAllAtOnce" type="boolean">
  `true` to send every email of a run together. Set this or `sendGap`, not both
</ParamField>

<ParamField body="sendGap" type="object">
  Spread the emails out: `{ "amount": 10, "unit": "minutes" }` with `unit` one of `minutes`, `hours`, `days`. At least 5 minutes and at most 30 days
</ParamField>

<ParamField body="textOnly" type="boolean">
  Send the emails as text only (no HTML). Overrides the campaign's HTML and tracking settings
</ParamField>

<ParamField body="schedule" type="object">
  `AUTO` only, required: when runs start (see below)
</ParamField>

<ParamField body="startsAt" type="string">
  `AUTO` only, required: first run time (ISO 8601, in the future)
</ParamField>

<ParamField body="endsAt" type="string">
  `AUTO` only: no run starts after this time. Use this or `maxRuns`, not both
</ParamField>

<ParamField body="maxRuns" type="number">
  `AUTO` only: stop after this many runs (1 to 1000)
</ParamField>

<RequestExample>

```bash cURL
curl -X POST "https://smartdelivery.smartlead.ai/api/v1/smart-delivery/tests?api_key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "MANUAL", "name": "Q4 Outbound - sequence step 1", "campaignId": 5614, "sequenceId": 20311, "providerIds": [1, 2], "emailAccountIds": [88101, 88102], "sendAllAtOnce": true}'
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.post(
    "https://smartdelivery.smartlead.ai/api/v1/smart-delivery/tests",
    params={"api_key": API_KEY}, json={"type": "MANUAL", "name": "Q4 Outbound - sequence step 1", "campaignId": 5614, "sequenceId": 20311, "providerIds": [1, 2], "emailAccountIds": [88101, 88102], "sendAllAtOnce": true}
)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';

const response = await fetch(
  `https://smartdelivery.smartlead.ai/api/v1/smart-delivery/tests?api_key=${API_KEY}`,
  {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({"type": "MANUAL", "name": "Q4 Outbound - sequence step 1", "campaignId": 5614, "sequenceId": 20311, "providerIds": [1, 2], "emailAccountIds": [88101, 88102], "sendAllAtOnce": true})
  }
);
console.log(await response.json());
```

## Response Codes

<ResponseField name="201" type="Success">
  Success
</ResponseField>

<ResponseField name="402" type="Error">
  No Smart Delivery plan, or no run credits left
</ResponseField>

<ResponseField name="404" type="Error">
  The campaign or variant does not exist (`VARIANT_NOT_FOUND`)
</ResponseField>

<ResponseField name="422" type="Error">
  Invalid provider (`INVALID_PROVIDER`), senders not attached to the campaign (`INVALID_SENDERS`), too many senders for your plan (`SENDER_LIMIT`), `startsAt` in the past (`STARTS_AT_IN_PAST`), or a schedule with no run before `endsAt` (`SCHEDULE_HAS_NO_RUNS`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
