<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. Contact support@smartlead.ai for access.
</Note>

## Overview

One item per completed run, oldest first. Without `from` and `to` it covers the last 30 days (UTC); the range is at most 400 days. A page holds the newest runs (up to 100), listed oldest first; use `nextCursor` to get the runs before them.

## Path Parameters

<ParamField path="id" type="string" required>
  Test ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<ParamField query="from" type="string">
  First day, `YYYY-MM-DD` (UTC)
</ParamField>

<ParamField query="to" type="string">
  Last day, `YYYY-MM-DD` (UTC)
</ParamField>

<ParamField query="limit" type="number">
  Page size, 1 to 100. Default 100
</ParamField>

<ParamField query="cursor" type="string">
  `nextCursor` from the previous page
</ParamField>

## Response Fields

<ResponseField name="from" type="string">First day of the range</ResponseField>
<ResponseField name="to" type="string">Last day of the range</ResponseField>
<ResponseField name="items" type="array">
  <Expandable title="run">
    <ResponseField name="runId" type="string">Run ID</ResponseField>
    <ResponseField name="runNo" type="number">Run number</ResponseField>
    <ResponseField name="completedAt" type="string">Completion time</ResponseField>
    <ResponseField name="score" type="number | null">Score</ResponseField>
    <ResponseField name="band" type="string | null">`poor`, `fair` or `good`</ResponseField>
    <ResponseField name="counts" type="object">Counts for the emails sent: `expected`, `sent`, `failed`, `inbox`, `tab`, `spam`, `missing`, `unreadable`, `notSent`, `unconfirmed`, `bouncedSeed`, `bouncedSender`, `bouncedUnknown`, `spfFail`, `dkimFail`, `dmarcFail`, and `inboxRate` (inbox share of the emails that reached a verdict, 0 to 1, or `null` when none did). Seed-side bounces (`bouncedSeed`) are left out of the placement rate; sender-side and unknown bounces count as not delivered.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="nextCursor" type="string | null">Pass as `cursor` to get the runs before this page. `null` when there are no more</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="400" type="Error">
  Invalid date range (`RANGE_INVALID`)
</ResponseField>

<ResponseField name="404" type="Error">
  Test not found (`TEST_NOT_FOUND`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
