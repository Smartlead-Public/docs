<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. Contact support@smartlead.ai for access.
</Note>

## Path Parameters

<ParamField path="emailAccountId" type="number" required>
  Smartlead email account ID
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<ParamField query="from" type="string">
  First day, `YYYY-MM-DD` (UTC). Default: 29 days before `to`
</ParamField>

<ParamField query="to" type="string">
  Last day, `YYYY-MM-DD` (UTC). Default: today. The range is at most 400 days
</ParamField>

<ParamField query="interval" type="string">
  `day` (default), `week` or `month`
</ParamField>

<ParamField query="providerId" type="number">
  Only this provider (ID from [List Seed Providers](/api-reference/smart-delivery-v2/providers))
</ParamField>

## Response Fields

<ResponseField name="from" type="string">First day</ResponseField>
<ResponseField name="to" type="string">Last day</ResponseField>
<ResponseField name="interval" type="string">`day`, `week` or `month`</ResponseField>
<ResponseField name="items" type="array">
  One item per interval, oldest first
  <Expandable title="bucket">
    <ResponseField name="bucket" type="string">First day of the interval, `YYYY-MM-DD`</ResponseField>
    <ResponseField name="runs" type="number">Completed runs in the range</ResponseField>
    <ResponseField name="counts" type="object">Counts for the emails sent: `expected`, `sent`, `failed`, `inbox`, `tab`, `spam`, `missing`, `unreadable`, `notSent`, `unconfirmed`, `bouncedSeed`, `bouncedSender`, `bouncedUnknown`, `spfFail`, `dkimFail`, `dmarcFail`, and `inboxRate` (inbox share of the emails that reached a verdict, 0 to 1, or `null` when none did). Seed-side bounces (`bouncedSeed`) are left out of the placement rate; sender-side and unknown bounces count as not delivered.</ResponseField>
    <ResponseField name="avgTimeToInboxMs" type="number | null">Average send-to-inbox time</ResponseField>
  </Expandable>
</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="400" type="Error">
  Invalid date range (`RANGE_INVALID`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
