<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. Contact support@smartlead.ai for access.
</Note>

## Overview

Hides the test everywhere, stops its schedule and turns off its share link. Reports are kept. The response has no body. An active `AUTO` test, or a test whose run is still sending, must be paused or stopped first.

## Path Parameters

<ParamField path="id" type="string" required>
  Test ID (UUID)
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b?api_key=YOUR_KEY"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.delete(
    "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/tests/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b",
    params={"api_key": API_KEY}
)
print(response.status_code)
```


</RequestExample>

## Response

On success the endpoint returns `204 No Content` with no body.

## Response Codes

<ResponseField name="204" type="Success">
  Done, no body
</ResponseField>

<ResponseField name="404" type="Error">
  Test not found
</ResponseField>

<ResponseField name="409" type="Error">
  A run is still in progress (`TEST_RUN_IN_PROGRESS`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
