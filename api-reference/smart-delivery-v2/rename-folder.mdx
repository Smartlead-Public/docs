title: "Rename Folder"
api: "PATCH https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/folders/{id}"
description: "Rename a folder"
---

<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Path Parameters

<ParamField path="id" type="number" required>
  Folder ID
</ParamField>

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

## Body Parameters

<ParamField body="name" type="string" required>
  New folder name, 1 to 100 characters
</ParamField>

<RequestExample>

```bash cURL
curl -X PATCH "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/folders/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b?api_key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Q4 outbound"}'
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.patch(
    "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/folders/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b",
    params={"api_key": API_KEY}, json={"name": "Q4 outbound"}
)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';

const response = await fetch(
  `https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/folders/3f2b8c1e-5d4a-4e7b-9a60-1c2d3e4f5a6b?api_key=${API_KEY}`,
  {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({"name": "Q4 outbound"})
  }
);
console.log(await response.json());
```

</RequestExample>

## Response Fields

<ResponseField name="id" type="number">Folder ID</ResponseField>
<ResponseField name="name" type="string">Folder name</ResponseField>
<ResponseField name="createdAt" type="string">Creation time (ISO 8601)</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="404" type="Error">
  Folder not found (`FOLDER_NOT_FOUND`)
</ResponseField>

<ResponseField name="409" type="Error">
  A folder with this name already exists (`FOLDER_EXISTS`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
