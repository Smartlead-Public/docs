<Note>
  **Smart Delivery v2 (Deliverability Test) API**: the deliverability (inbox placement) test that sends your campaign email to seed inboxes and reports where it landed. It is separate from the Smart Delivery spam test endpoints. Contact support@smartlead.ai for access.
</Note>

## Overview

Check your remaining run credits and the limits that apply before you create a test.

## Query Parameters

<ParamField query="api_key" type="string" required>
  Your SmartLead API key
</ParamField>

<RequestExample>

```bash cURL
curl -X GET "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/limits?api_key=YOUR_KEY"
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.get(
    "https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/limits",
    params={"api_key": API_KEY}
)
print(response.status_code)
print(response.json())
```

```javascript JavaScript
const API_KEY = 'YOUR_API_KEY';

const response = await fetch(
  `https://sl-sd-api.smartlead.ai/api/v1/smart-delivery/limits?api_key=${API_KEY}`,
  {
    method: 'GET'

console.log(await response.json());
```

</RequestExample>

## Response Fields

<ResponseField name="maxSendersPerTest" type="number">Sender mailboxes your plan allows in one test</ResponseField>
<ResponseField name="runCreditsRemaining" type="number">Run credits left on your plan</ResponseField>
<ResponseField name="seedsPerSenderPerProvider" type="number">Seed inboxes each sender mails per provider</ResponseField>
<ResponseField name="minGapMinutes" type="number">Smallest allowed `sendGap`, in minutes</ResponseField>
<ResponseField name="sendJitterSeconds" type="object">`min` and `max` random delay, in seconds, added to each send</ResponseField>
<ResponseField name="placementWindowMinutes" type="number">How long after the last send the placement check keeps looking for each email</ResponseField>

## Response Codes

<ResponseField name="200" type="Success">
  Success
</ResponseField>

<ResponseField name="402" type="Error">
  No Smart Delivery plan on the account (`NO_PLAN`)
</ResponseField>

<ResponseField name="401" type="Unauthorized">
  Missing, invalid or expired API key (`UNAUTHORIZED`)
</ResponseField>

<ResponseField name="403" type="Forbidden">
  Client (agency) API keys are not allowed (`CLIENT_NOT_ALLOWED`), or your plan does not include API access (`API_ACCESS_RESTRICTED`)
</ResponseField>

<ResponseField name="429" type="Too Many Requests">
  Too many requests for this API key. Wait the number of seconds in the `Retry-After` header (`RATE_LIMITED`)
</ResponseField>
